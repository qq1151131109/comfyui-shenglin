# ComfyUI Shenglin - 圣林的自定义节点集合

一个功能完整的ComfyUI自定义节点集合，包含AI文生图、语音合成、视频制作等完整工具链。

## 🎯 功能模块

### 🎨 RunningHub API 集成 (3个节点)
- **RunningHub Flux文生图** - 基于Flux模型的批量文生图，支持并发处理
- **RunningHub Qwen高级版** - 支持自定义尺寸(720x1280)和高级参数的Qwen文生图
- **RunningHub Qwen文生图** - 快捷版Qwen文生图，支持横屏/竖屏/正方形比例

### 🎵 MiniMax TTS 语音合成 (3个节点)
- **MiniMax批量TTS** - 多行文本批量语音合成，支持并发处理
- **MiniMax TTS (Dynamic)** - 动态音色TTS，支持所有可用音色
- **批量音频预览** - ComfyUI界面内直接预览音频文件

### 🎬 视频合成系统 (5个节点)
- **视频合成器** - Ken Burns效果，智能缩放动画，内存优化流式处理
- **视频预览器** - ComfyUI界面内直接预览视频文件
- **故事时间轴构建器** - 微秒级精度时间轴计算，智能字幕分割
- **故事动画处理器** - 关键帧动画系统，奇偶交替缩放
- **故事视频合成器** - 5轨道音频合成，双字幕系统

### 🔄 批量工作流执行器 (1个节点)
- **批量工作流执行器** - 分布式批量执行ComfyUI工作流，支持占位符替换和多实例并行处理

## 🚀 特色功能

- **完整工具链**: 从AI文生图 → 语音合成 → 视频制作的完整流程
- **并发处理**: 支持批量并发，提高生产效率
- **内存优化**: 视频处理使用流式算法，避免OOM问题
- **界面预览**: 支持音频、视频在ComfyUI界面内直接预览
- **参数丰富**: 提供专业级的参数控制选项
- **基于Coze**: 视频系统基于Coze工作流完整复刻

## 🔄 批量工作流执行器详细说明

### 功能描述
将ComfyUI工作流分发到多个实例并行执行，支持占位符替换，实现真正的分布式批量生图。

### 使用方法
在ComfyUI中：**右键 → Add Node → 🔥 Shenglin/工作流 → 🔄 批量工作流执行器**

### 参数说明

#### 必需参数：
- **`workflow_json`** (多行文本)
  - **作用**: 粘贴你的ComfyUI API工作流JSON代码
  - **获取方式**: 在ComfyUI界面中设置好工作流 → 开启开发者模式 → Save (API Format)
  - **占位符**: 在需要批量替换的地方使用`{{PROMPT}}`等占位符

- **`comfyui_instances`** (多行文本)
  - **作用**: ComfyUI服务器地址列表，每行一个
  - **格式**:
    ```
    http://192.168.1.100:8188
    http://192.168.1.101:8188
    http://192.168.1.102:8188
    ```
  - **支持格式**: 完整URL、IP:端口、域名等

- **`prompt_list`** (多行文本)
  - **作用**: 提示词列表，每行一个
  - **示例**:
    ```
    beautiful sunset over mountains
    cute cat playing with yarn
    futuristic cityscape at night
    ```

#### 可选参数：
- **`placeholder`** (文本，默认: `{{PROMPT}}`)
  - **作用**: 主要占位符，会被`prompt_list`中的提示词逐一替换
  - **注意**: 必须与工作流JSON中的占位符完全一致


- **`timeout_seconds`** (整数，默认: 300，范围: 60-1800)
  - **作用**: 单个任务超时时间（秒）
  - **建议值**:
    - 简单图片生成: 60-120秒
    - 复杂工作流: 300-600秒
    - 视频生成: 600-1800秒

### 输出结果
- **`execution_summary`**: 执行摘要，包含成功率、执行时间、服务器状态等统计信息
- **`results_json`**: 详细结果JSON，包含每个任务的完整执行结果

### 使用示例

#### 基础用法 - 批量文生图
```json
// workflow_json中包含:
{
  "6": {
    "inputs": {
      "text": "{{PROMPT}}"
    },
    "class_type": "CLIPTextEncode"
  }
}

// comfyui_instances:
http://192.168.1.100:8188
http://192.168.1.101:8188

// prompt_list:
beautiful landscape
cute animal
amazing architecture
```

#### 高级用法 - 固定参数工作流
如果需要固定某些参数，直接在工作流JSON中写死即可：
```json
{
  "positive_prompt": "{{PROMPT}}",
  "negative_prompt": "bad quality, blurry, distorted",
  "steps": 25,
  "cfg_scale": 7.5
}
```
这样所有任务都会使用相同的负面提示词、步数和CFG值。

### 实际应用场景

#### 📸 批量生图
- 用100个不同提示词生成图片
- 分发到10台服务器，每台处理10个任务
- 执行时间从100分钟缩短到10分钟

#### 🎨 参数对比测试
- 同一个提示词用不同步数/CFG值生成
- 快速对比不同参数效果
- 选择最佳参数组合

#### 🏭 生产环境批量处理
- 大批量图片生产
- 自动负载均衡和容错处理
- 后台自动重试失败任务（最多重试2次）

### 故障排除

**❌ "没有可用的ComfyUI实例"**
- 检查服务器地址格式是否正确
- 确认所有服务器正在运行
- 测试网络连接是否正常

**❌ "工作流中未找到占位符"**
- 确认占位符拼写和大小写完全匹配
- 检查JSON格式是否正确
- 确保占位符包含在引号内

**❌ "任务执行超时"**
- 增大`timeout_seconds`参数值
- 检查服务器负载情况
- 简化工作流复杂度

### 技术特性
- ✅ **健康检查**: 自动检测服务器状态，只在健康实例上执行
- ✅ **失败重试**: 任务失败时自动重试，提高成功率（后台自动重试2次）
- ✅ **智能并发**: 根据服务器数量自动决定并发数，避免过载单个服务器
- ✅ **进度监控**: 实时监控执行状态，提供详细执行报告
- ✅ **占位符替换**: 支持多层级占位符，实现复杂参数组合
