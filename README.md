# ComfyUI Shenglin - 圣林的自定义节点集合

一个功能完整的ComfyUI自定义节点集合，包含RunningHub API集成、MiniMax TTS语音合成、AI视频制作等完整工具链。

## 🎯 功能模块

### 🎨 RunningHub API 集成 (14个节点)
**文生图节点：**
- **RunningHub Flux文生图** - 基于Flux模型的批量文生图，支持并发处理
- **RunningHub Qwen高级版** - 支持自定义尺寸和高级参数的Qwen文生图
- **RunningHub Qwen文生图** - 快捷版Qwen文生图，支持多种比例预设

**图生视频节点：**
- **RunningHub Wan2.2图生视频** - 基于Wan2.2 14B+LightX2V模型，90秒81帧6步超极速图生视频
- **RunningHub InfiniteTalk数字人** - 基于InfiniteTalk+Wan2.1模型，音频驱动数字人说话视频生成

**辅助功能节点：**
- **RH执行节点** - RunningHub工作流执行器
- **RH设置节点** - API配置和参数设置
- **RH节点信息列表** - 节点状态和信息管理
- **RH任意转字符串** - 数据类型转换工具
- **RH提取图片** - 从列表中提取图片
- **RH批量图片** - 图片批量处理
- **RH音频上传** - 音频文件上传到RunningHub
- **RH视频上传** - 视频文件上传到RunningHub
- **RH图片上传** - 图片文件上传到RunningHub

### 🎵 MiniMax TTS 语音合成 (3个节点)
- **MiniMax批量TTS** - 多行文本批量语音合成，支持14种音色和并发处理
- **MiniMax TTS (Dynamic)** - 动态音色TTS，支持实时参数调整
- **批量音频预览** - ComfyUI界面内直接预览音频文件

### 🎬 AI视频制作系统 (3个节点)
- **AI视频制作器** - 完整的视频合成系统，支持多视频拼接和音频处理
- **视频合成器-基于图片** - 将静态图片转换为动态视频，集成音效库和动画效果
- **视频预览器** - ComfyUI界面内直接预览视频文件

### 📰 RSS内容处理套件 (11个节点)
**基础RSS工具：**
- **RSS订阅解析器** - RSS源解析和内容获取
- **文章内容提取器** - AI智能提取完整文章内容
- **RSS文本处理器** - 文本清理和格式化处理
- **RSS缓存管理器** - 智能缓存管理和性能优化

**智能分析工具：**
- **多源RSS收集器** - 并行收集多个RSS源内容
- **批量文章提取器** - 批量处理文章内容提取
- **内容去重器** - 智能识别和去除重复内容
- **话题聚类引擎** - 机器学习驱动的话题分类和聚类
- **话题报告生成器** - 生成详细的话题分析报告
- **内容导出器** - 多格式内容导出(JSON/CSV/HTML/Markdown)
- **选定话题查看器** - 特定话题内容详情和写作素材

### 🎤 Whisper语音识别套件 (4-7个节点)
**基础语音识别：**
- **Apply Whisper** - Whisper语音转文字，支持多语言识别
- **Add Subtitles To Frames** - 为视频帧添加字幕
- **Add Subtitles To Background** - 为背景图片添加字幕

**增强功能（可选）：**

### ✂️ 视频编辑工具套件 (2个节点)
- **视频智能裁切** - 基于内容的智能视频裁切和预览
- **视频合并工具** - 多个视频文件的无缝合并

## 📦 安装使用

1. 克隆到ComfyUI自定义节点目录:
```bash
cd /path/to/ComfyUI/custom_nodes
git clone https://github.com/qq1151131109/comfyui-shenglin.git
```

2. 安装依赖（可选，大部分功能无需额外依赖）:
```bash
cd comfyui-shenglin
pip install -r requirements.txt
```

**可选增强功能依赖：**
```bash
# Whisper增强功能 (WhisperX对齐、Remotion字幕)
pip install whisperx
pip install remotion

# LLM大语言模型功能 (需要先安装comfyui_LLM_party)
# 请参考 https://github.com/heshengtao/comfyui_LLM_party
```

3. 重启ComfyUI即可使用

## 🔑 API配置

### RunningHub API
需要在 [RunningHub](https://www.runninghub.cn) 注册获取API密钥
- 支持Flux文生图、Qwen文生图、Wan2.2图生视频
- 工作流ID自动管理，无需手动配置

### MiniMax API
需要在 [MiniMax](https://www.minimaxi.com) 注册获取API密钥和Group ID
- 支持14种专业音色（青涩/精英/霸道/大学生/少女/御姐/成熟/甜美/主持人/有声书）
- 支持多种模型：speech-2.5-hd-preview（推荐）等

### RSS内容处理
无需API配置，支持所有公开RSS源
- 智能内容提取，支持80+种语言
- 机器学习话题聚类，中文jieba分词优化
- 企业级缓存系统，支持高并发访问

- **参数精调**: 语速(0.5-2.0)、音量、音调独立调节
- **音色丰富**: 14种专业音色，适配不同场景

### RSS智能内容分析
- **双套系统**: 基础RSS工具(4个) + 智能分析系统(7个)
- **智能工作流**: 多源收集 → 批量提取 → 内容去重 → 话题聚类 → 报告生成 → 写作素材
- **机器学习**: TF-IDF特征提取 + K-means/DBSCAN聚类算法
- **多格式导出**: JSON(开发) + CSV(分析) + HTML(展示) + Markdown(文档)
- **中文优化**: jieba分词 + 中文停用词 + 语义化标签生成

## 🔄 批量工作流执行器详细说明

### 功能描述
将ComfyUI工作流分发到多个实例并行执行，支持占位符替换，实现真正的分布式批量生图。

### 使用方法
在ComfyUI中：**右键 → Add Node → 🔥 Shenglin/工作流 → 🔄 批量工作流执行器**

### 参数说明

#### 必需参数：
- **`workflow_json`** (多行文本)
  - **作用**: 粘贴你的ComfyUI API工作流JSON代码
  - **获取方式**: 在ComfyUI界面中设置好工作流 → 开启开发者模式 → Save (API Format)
  - **占位符**: 在需要批量替换的地方使用`{{PROMPT}}`等占位符

- **`comfyui_instances`** (多行文本)
  - **作用**: ComfyUI服务器地址列表，每行一个
  - **格式**:
    ```
    http://192.168.1.100:8188
    http://192.168.1.101:8188
    http://192.168.1.102:8188
    ```
  - **支持格式**: 完整URL、IP:端口、域名等

- **`prompt_list`** (多行文本)
  - **作用**: 提示词列表，每行一个
  - **示例**:
    ```
    beautiful sunset over mountains
    cute cat playing with yarn
    futuristic cityscape at night
    ```

#### 可选参数：
- **`placeholder`** (文本，默认: `{{PROMPT}}`)
  - **作用**: 主要占位符，会被`prompt_list`中的提示词逐一替换
  - **注意**: 必须与工作流JSON中的占位符完全一致


- **`timeout_seconds`** (整数，默认: 300，范围: 60-1800)
  - **作用**: 单个任务超时时间（秒）
  - **建议值**:
    - 简单图片生成: 60-120秒
    - 复杂工作流: 300-600秒
    - 视频生成: 600-1800秒

### 输出结果
- **`execution_summary`**: 执行摘要，包含成功率、执行时间、服务器状态等统计信息
- **`results_json`**: 详细结果JSON，包含每个任务的完整执行结果

### 使用示例

#### 基础用法 - 批量文生图
```json
// workflow_json中包含:
{
  "6": {
    "inputs": {
      "text": "{{PROMPT}}"
    },
    "class_type": "CLIPTextEncode"
  }
}

// comfyui_instances:
http://192.168.1.100:8188
http://192.168.1.101:8188

// prompt_list:
beautiful landscape
cute animal
amazing architecture
```

#### 高级用法 - 固定参数工作流
如果需要固定某些参数，直接在工作流JSON中写死即可：
```json
{
  "positive_prompt": "{{PROMPT}}",
  "negative_prompt": "bad quality, blurry, distorted",
  "steps": 25,
  "cfg_scale": 7.5
}
```
这样所有任务都会使用相同的负面提示词、步数和CFG值。

### 实际应用场景

#### 📸 批量生图
- 用100个不同提示词生成图片
- 分发到10台服务器，每台处理10个任务
- 执行时间从100分钟缩短到10分钟

#### 🎨 参数对比测试
- 同一个提示词用不同步数/CFG值生成
- 快速对比不同参数效果
- 选择最佳参数组合

#### 🏭 生产环境批量处理
- 大批量图片生产
- 自动负载均衡和容错处理
- 后台自动重试失败任务（最多重试2次）

### 故障排除

**❌ "没有可用的ComfyUI实例"**
- 检查服务器地址格式是否正确
- 确认所有服务器正在运行
- 测试网络连接是否正常

**❌ "工作流中未找到占位符"**
- 确认占位符拼写和大小写完全匹配
- 检查JSON格式是否正确
- 确保占位符包含在引号内

**❌ "任务执行超时"**
- 增大`timeout_seconds`参数值
- 检查服务器负载情况
- 简化工作流复杂度

### 技术特性
- ✅ **健康检查**: 自动检测服务器状态，只在健康实例上执行
- ✅ **失败重试**: 任务失败时自动重试，提高成功率（后台自动重试2次）
- ✅ **智能并发**: 根据服务器数量自动决定并发数，避免过载单个服务器
- ✅ **进度监控**: 实时监控执行状态，提供详细执行报告
- ✅ **占位符替换**: 支持多层级占位符，实现复杂参数组合
