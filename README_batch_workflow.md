# 🔄 批量工作流执行器

将ComfyUI工作流分发到多个实例并行执行，支持占位符替换，实现真正的分布式批量生图。

## 核心功能

✅ **占位符替换**：用简单的`{{PROMPT}}`等占位符标记工作流中需要替换的部分
✅ **多实例分发**：自动将任务分发到多个ComfyUI服务器并行执行
✅ **健康检查**：自动检测服务器状态，只在健康实例上执行
✅ **失败重试**：任务失败时自动重试，提高成功率
✅ **并发控制**：可控制同时执行的任务数量，避免服务器过载
✅ **进度监控**：实时监控执行状态，提供详细执行报告

## 使用方法

### 1. 准备工作流

在你的ComfyUI API工作流JSON中，将需要批量替换的部分用占位符标记：

```json
{
  "6": {
    "inputs": {
      "text": "{{PROMPT}}"
    },
    "class_type": "CLIPTextEncode"
  },
  "7": {
    "inputs": {
      "text": "{{NEGATIVE}}"
    },
    "class_type": "CLIPTextEncode"
  }
}
```

### 2. 配置节点

在ComfyUI中：**右键 → Add Node → 🎨 Shenglin/Workflow → 🔄 批量工作流执行器**

**必需参数：**
- `workflow_json`: 粘贴你的工作流JSON
- `comfyui_instances`: 服务器地址列表，每行一个：
  ```
  http://192.168.1.100:8188
  http://192.168.1.101:8188
  http://192.168.1.102:8188
  ```
- `prompt_list`: 提示词列表，每行一个：
  ```
  beautiful sunset over mountains
  cute cat playing with yarn
  futuristic cityscape at night
  ```

**可选参数：**
- `placeholder`: 主要占位符（默认: `{{PROMPT}}`）
- `replacement_config`: 额外替换配置，格式：
  ```
  {{NEGATIVE}}=blurry, low quality
  {{STEPS}}=30
  {{CFG}}=7.5
  ```

### 3. 执行结果

节点执行后会返回：
- **执行摘要**：成功率、执行时间、服务器状态等统计信息
- **详细结果JSON**：每个任务的完整执行结果

## 高级用法

### 多占位符替换

```json
{
  "workflow_json": "你的工作流...",
  "placeholder": "{{PROMPT}}",
  "replacement_config": "{{NEGATIVE}}=bad quality, blurry\n{{SEED}}=12345\n{{STEPS}}=25"
}
```

### 服务器地址支持格式

```
# 完整URL
http://192.168.1.100:8188

# IP:端口 (自动补充http://)
192.168.1.100:8188

# 域名
comfyui.local:8188
```

## 实际应用场景

### 📸 批量生图
- 用100个不同提示词生成图片
- 分发到10台服务器，每台处理10个任务
- 执行时间从100分钟缩短到10分钟

### 🎨 风格测试
- 同一个提示词用不同模型/参数生成
- 快速对比不同效果
- 选择最佳参数组合

### 🏭 生产环境
- 大批量图片生产
- 负载均衡和容错处理
- 自动重试失败任务

## 性能优化建议

1. **并发控制**：根据服务器性能调整`max_concurrent`
   - GPU内存充足：3-5个并发
   - GPU内存紧张：1-2个并发

2. **超时设置**：根据工作流复杂度调整`timeout_seconds`
   - 简单图片生成：60-120秒
   - 复杂视频生成：300-600秒

3. **重试策略**：网络不稳定时启用重试
   - 内网环境：禁用重试（`enable_retry=False`）
   - 公网环境：启用重试，2-3次

## 故障排除

**❌ "没有可用的ComfyUI实例"**
- 检查服务器地址是否正确
- 确认服务器正在运行
- 检查网络连接

**❌ "工作流中未找到占位符"**
- 确认占位符拼写正确
- 注意大小写匹配
- 检查JSON格式

**❌ "任务执行超时"**
- 增大`timeout_seconds`
- 检查服务器负载
- 简化工作流复杂度
